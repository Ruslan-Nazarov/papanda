ОБОСНОВАНИЕ ТРЁХ УСЛОВИЙ (дано автором простейшего процесса — не доверяйте на слово, проверьте по существу):
{three_conditions_block}

## Алгоритм
Простейшим процесс считается, только если ОДНОВРЕМЕННО выполняются три условия (п. 4.3 главного промпта):
1. Он связан с целью как процессом.
2. Из него вытекают развивающие его процессы, приближение к полной совокупности которых описывает цель — то есть простейший процесс должен быть настолько базовым, чтобы цель разворачивалась ИЗ него, а не рядом с ним.
3. Каждый из этих потенциальных развивающих процессов сам, в свою очередь, связан именно с этим простейшим процессом (а не с каким-то другим понятием).

Проверьте каждое условие по отдельности — не считайте достаточным то, что автор просто заявил связь словами «связано» или «влияет»: должен быть виден механизм. Частая ошибка — взять слишком общее или слишком частное понятие вместо настоящего простейшего процесса (например, взять само явление из запроса как «простейший процесс» — это не простейший процесс, а переформулировка цели).

Ответьте СТРОГО в формате JSON:
{
  "valid": true,
  "checks": {
    "связан_с_целью": true,
    "порождает_совокупность": true,
    "каждый_развивающий_связан_обратно": true
  },
  "reason": "…"
}
`reason` — обязательно, даже при `valid: true` (коротко, что убедило); при `valid: false` — что именно из трёх условий не выполняется и почему.
