Задача: по готовому диалектическому конспекту (Шаги 1–5) выдать: короткие заголовки к каждому шагу, название всего конспекта и итоговый вывод.

## Заголовки (`titles`) — для КАЖДОГО процесса
Один короткий заголовок на каждый ключ шага. Заголовок — это самая суть того, что в блоке, в одно предложение (можно без глагола, до ~12 слов). По заголовкам одним взглядом должна читаться вся схема ответа. Обычными словами, БЕЗ терминов алгоритма («простейший процесс», «противоречие», «разрешение», «единство» и т.п.). НЕ повторяйте роль шага. Для Шага 4 — что с чем не сходится; для Шага 5 — что именно снимает эту несовместимость.
Пример: `"1": "Выпечка хлеба: мягкий тёплый мякиш из теста"`, `"3": "Разогрев с водой возвращает мякишу мягкость"`.

## Название конспекта и вывод (`note_title`, `anchor_title`, `anchor_summary`)
- `note_title` — короткое название всего конспекта: именная группа из 2–6 слов, НЕ вопрос. «почему небо голубое» → «Синева неба и рассеяние света».
- `anchor_title` — исходный запрос, развёрнутый в утвердительный ответ одной строкой (до ~10 слов). «почему небо голубое» → «Небо голубое из-за рассеяния коротких волн».
- `anchor_summary` — 2–4 предложения: итог всего разбора, прямой ответ на исходный запрос обычными словами, как объяснили бы человеку, который только что всё понял. Начните с самого ответа. Без терминов алгоритма. Это не пересказ шагов по порядку, а собранная вместе суть: что оказалось главным и почему.

## Формат ответа — СТРОГО JSON
```
{
  "titles": {"1": "…", "2.1": "…", "2.2": "…", "3": "…", "4": "…", "5": "…"},
  "note_title": "…",
  "anchor_title": "…",
  "anchor_summary": "…"
}
```
Ключи в `titles` — ровно те, что есть в конспекте (включая «2.1», «2.2» и т.п.). Обращение на «вы». Язык — как у конспекта.
