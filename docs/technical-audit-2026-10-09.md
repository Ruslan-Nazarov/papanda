# Техническая проверка приложения — 9 октября 2026

Проверены технические сценарии редактора и управления заметками. Авторские промпты и методология в рамках этой проверки не менялись. Живые запросы к языковым моделям не выполнялись. Браузерные сценарии используют отдельные временные базы и отключённые ключи внешних сервисов.

## Исправления

| Сценарий | Причина сбоя | Изменение |
| --- | --- | --- |
| Создать заметку из списка; удалить последнюю заметку | Вызывался отсутствующий `NoteStorageService.createNewNote` | Добавлен общий переход к новой заметке, очищающий URL и указатель последнего документа |
| Открыть заметку из окна связей | Вызывался отсутствующий `NoteController.loadNote` | Используется общий сервис навигации |
| Переключиться через список, связи или «Назад» с несохранёнными правками | Загруженный документ заменял текущий без сохранения | Переход сохраняет текущие правки, включая изменения во время загрузки; ошибка сохранения оставляет документ открытым |
| Неудачный переход «Назад» | История сокращалась до успешной загрузки | История изменяется после успешного перехода |
| Быстро переключать список и корзину, менять строку поиска | Поздний ответ перерисовывал уже другую вкладку | Проверяются номер запроса, активная вкладка и наличие диалога; отложенный поиск отменяется |
| Удалить категорию текущей заметки и продолжить сохранение | Сервер изменял ревизию заметки, а редактор продолжал отправлять старую | Категория отсоединяется обычным сохранением с проверкой ревизии до удаления |
| Переименовать категорию с кавычками | Экранирование текста не защищало значение HTML-атрибута | Используется общий `HtmlSafety.escape` |
| Перетащить блок при наличии скрытого черновика или якоря с вложением | Новый список строился только из отображённых карточек | Сохраняются все блоки документа; меняется порядок видимых позиций. Внешнее перетаскивание текста больше не перехватывается глобально |
| Экспортировать текст с формулами | Регулярное выражение удаляло теги вместе с исходной формулой в атрибуте | Экспорт использует DOM-разбор, сохраняет LaTeX, абзацы и Unicode-сущности |
| Искать `<`, `&` и выражения с ними | Подсветка вставлялась внутрь уже экранированных HTML-сущностей | Совпадения выделяются до экранирования; поиск использует читаемый текст с формулами |
| Редактировать нумерованный список | Расширение `orderedList` было отключено | Восстановлена поддержка списка, в том числе начального номера |
| Отменить изменение рисунка | Цвет, толщина, сетка и блокировка не всегда записывались; массовые операции создавали промежуточные снимки | История сохраняет изменения свойств, исключает дубликаты, объединяет копирование/очистку/массовое удаление в одну операцию |
| Копировать несколько выделенных фигур | Проверялось несовместимое с Fabric 7 строковое имя типа | Используется `isType('ActiveSelection')`; фигуры остаются отдельными объектами |
| Сохранить заблокированную фигуру | Свойства блокировки не включались в JSON | Свойства движения, поворота, масштаба и управляющих маркеров сохраняются явно |
| Перейти по внутренней ссылке к блоку | Использовался лишний префикс `block-`; числовой ID заметки сравнивался со строкой | Поиск использует реальный ID блока; ссылка внутри текущей заметки не перезагружает её |

## Проверки

Финальные результаты: pytest — **356 passed, 4 skipped**; frontend — **67 passed**; Chromium — **36 passed**. Сборка, ESLint, настроенная проверка типов (`ApiContracts.js`) и `git diff --check` прошли. Проверка типов в проекте пока не охватывает весь JavaScript.

Новые регрессии: `tests/frontend/technical-flows.test.cjs`, `tests/browser/editor-widgets.test.cjs` и дополнительные сценарии в `tests/browser/app.test.cjs`.

Браузерная проверка охватывает ручное редактирование, форматирование и undo/redo, формулы, графики, рисунки, сохранение и повторное открытие, вложения, стикеры, версии и восстановление, категории, список заметок, корзину, связи, внутренние ссылки, публичный просмотр, локальную библиотеку, переключение языка и узкий экран. Контролируются необработанные ошибки и нарушения CSP.

Серверный набор также проверяет CRUD, миграции, импорт документов, санитизацию, ограничения загрузки, историю, резервное копирование и границы доступа. Генерационные тесты в общей suite работают с подставными ответами.

Это проверка конкретной локальной рабочей копии в Chromium, а не гарантия отсутствия ошибок во всех браузерах и состояниях. Системный диалог печати, реальный принтер и внешние сервисы не проверялись. Изменения не публиковались и не развёртывались на сервере.
