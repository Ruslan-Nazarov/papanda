# Исправления по повторному аудиту 28 сентября

## Хранение

- Страницы и 404 не занимают места в реестре. Главная выдаёт подписанный
  предварительный cookie без записи в SQLite: первые параллельные запросы API
  получают одну идентичность. Реестр создаётся при обращении к API.
- Общий предел сессий по умолчанию отключён (`DEMO_MAX_SESSIONS=0`).
- Активность продлевает cookie и срок сессии на 30 дней. Автоматическое удаление
  выключено (`DEMO_DELETE_EXPIRED_DATA=false`). Данные сохраняются после истечения
  cookie; потеря самого cookie всё ещё требует отдельного восстановления доступа.
- Прежний UUID-cookie восстанавливает только свою базу через SQLite backup;
  исходный файл сохраняется. Повторное восстановление не перезаписывает новые правки.
- `python -m scripts.recover_legacy_sessions --data-dir /path/to/data` проверяет
  перенос непустых старых баз на временных копиях. `--apply` выполняется после
  резервного копирования и остановки службы; восстанавливает также публичные ссылки.
- Снято ограничение названия конспекта в 150 символов. Общий предел HTTP-запроса
  продолжает защищать сервер от чрезмерного объёма данных.

## Движок

- Конспект, уточнение и предложение отдельного шага используют выбранный движок v3.
  Для предложения шага выполняется полный алгоритм с контекстом существующей записи,
  но возвращается только выбранная группа блоков. Это может занимать столько же
  времени, сколько полный запуск; остальные группы не заменяются.
- Документ, существующие шаги и уточнение передаются модели отдельным сообщением
  данных на каждом вызове. Тексты шести английских авторских промптов не менялись.
- Отображаются все процессы всех итераций, без прежнего обрезания до четырёх.
- Закрытие потока/отмена/таймаут отменяют builder и ожидание очереди; HTTP-клиенты
  закрываются. Транспорт OpenAI-compatible переведён с неотменяемого фонового
  потока на async HTTP. Уже принятую внешним провайдером работу отмена HTTP
  не гарантирует отменить на стороне провайдера, но новых повторов приложение не делает.
- Каждый запрос модели, повтор и fallback учитываются общим бюджетом; ошибки
  бюджета прекращают цепочку. Сохраняются измеренные токены и статус каждой попытки.
- Формулы, разбор статьи и вспомогательный диалог остаются отдельными функциями
  приложения; они не являются шестиступенчатым построением диалектического мира.

## Развёртывание

Сохраняется восстановленный push → проверка → deploy в `/root/papanda`.
Ограничения безопасного импорта, изоляция пользователей, revision/409 и резервные
копии миграций не отключаются. Перед очисткой старых релизов сертификат GigaChat
переносится в постоянный каталог данных.
