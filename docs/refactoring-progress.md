требует пересмотра теста/отметки. Linux-установка локально не исполнялась;
платформенные ветви lock должны пройти CI перед выпуском.

В песочнице Codex Chromium и стандартный системный Temp pytest потребовали
разрешения. Для временных Python-файлов внутри workspace подходит уникальный
`--basetemp=.cache/<имя-прогона>`; не указывать туда пользовательские данные,
поскольку pytest очищает этот каталог.
