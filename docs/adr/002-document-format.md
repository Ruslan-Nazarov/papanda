# ADR 002 — формат документа и редактирование

Принято: 24.09.2026, R3/R5/R6.

**Контекст.** Блоки содержат rich HTML, формулы, рисунки и дополнительные
метаданные. Прямые мутации и параллельные сохранения теряли изменения.

**Решение.** Документ и блок имеют schema_version=1, документ — revision.
ID блоков стабильны, HTML проверяется на сервере и при выводе. NoteStore
владеет состоянием, SaveCoordinator сериализует снимки. PATCH требует revision;
409 сохраняет локальный текст и предлагает явное разрешение конфликта.

Общие стикеры — отдельный массив с id/title/text/color/created_at. Они входят
в историю и приватный экспорт; публичный DTO исключает личные стикеры.

**Следствия.** JSON остаётся расширяемым для существующих данных; переход на
нормализованные таблицы блоков пока не нужен. Версия SQLite (2) независима
от версии формата документа (1). TypeScript применяется к границе DTO,
остальной frontend остаётся JS с ESLint.
