# ADR 001 — владелец данных

Принято: 24.09.2026, R3/R6.

**Контекст.** Проект объединяет личный редактор и временное публичное demo.
Аккаунтов и подтверждённой принадлежности старых cookie нет.

**Решение.** Личный режим доступен только напрямую с loopback. Demo использует
один процесс, серверный реестр случайных сессий и отдельную SQLite на сессию.
Публичный токен разрешает только чтение allowlist DTO; токен не создаёт сессию.

**Следствия.** Demo имеет ограниченный TTL, размер и число БД. Cookie клиента
не выбирает произвольный файл. Для постоянных аккаунтов потребуется отдельная
модель owner_id и миграция: это не скрытая возможность текущего режима.
