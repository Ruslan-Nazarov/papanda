# Развитие учебного сценария

## Согласованный план

1. Варианты конспекта создаются только по кнопке. Ветка от шага N сохраняет
   предыдущие шаги и начинает N–5 заново. Каждый вариант хранит собственные
   версии; исходный вариант остаётся доступен. Варианты можно сравнивать по шагам.
2. Генерация отдельного шага сначала показывает предложение ИИ. Студент может
   принять, изменить и принять либо отклонить его. Полный конспект ИИ сохраняется
   отдельным вариантом для сравнения и критической оценки.
3. Общий вопрос по теме открывает отдельный диалог с контекстом текущего
   варианта. Ответ не меняет блоки. Диалог и значимые решения сохраняются в
   истории работы; обычный набор текста не журналируется.
4. Общий каталог, оценки понятности, карта учебника, портфолио и виды
   преподавателя/работодателя отображаются как явно помеченный прототип.
   Публикация и отзывы ожидают аккаунтов. Существующие публичные ссылки
   работают независимо от прототипа.
5. Долгосрочная задача отмечается у конспекта; связанные конспекты можно
   объединять существующим механизмом связей.

## Текущая реализация

- Миграция SQLite 003 добавляет семьи вариантов, поля происхождения и журнал
  значимых действий. Перед миграцией существующей базы создаётся резервная копия.
- Журнал содержит создание вариантов, обращения к ИИ, решения по предложениям,
  вопросы и ответы, оценку полного конспекта ИИ и отметку долгосрочной задачи.
- Новые экраны открываются из верхней панели и главного меню. Сообщество
  использует только демонстрационные данные; локальные названия конспектов в
  макете портфолио не публикуются.

## Границы прототипа

Реальной регистрации, межпользовательского каталога, голосования, ролей,
доступа работодателя и преподавателя пока нет. Демонстрационные отзывы
обозначены как примеры. Качество ответов ИИ зависит от настроенного провайдера
и отдельно проверяется на реальных конспектах.
