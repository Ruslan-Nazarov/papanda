# Редактор после R5

## Состояние и сохранение

`NoteStore` владеет документом. `AppState.currentNote` и вложенные блоки —
read-only представления: запись, удаление поля или изменение массива напрямую
вызывают ошибку. Изменения проходят через `updateNote`, `updateBlock`,
`addBlock` и `removeBlock`. Команды копируют входные данные, отмечают dirty
и увеличивают локальную ревизию; повторная установка того же значения — no-op.
Это граница ответственности модулей, а не защита от произвольного кода страницы.

| Модуль | Ответственность |
|---|---|
| NoteStore / AppState | Документ, команды, dirty, локальная ревизия и эпоха открытого документа |
| NotesAPI / ApiContracts | HTTP, проверка SSE и проверка DTO до использования |
| SaveCoordinator | Одна очередь записи на документ, снимок payload, повторная запись поздних правок |
| NoteStorageService | Загрузка с защитой от устаревшего ответа, совместимый фасад сохранения |
| AIController / GenerationChanges | Отмена запуска, проверка исходной ревизии, атомарное применение результата |
| BlockDOMRenderer / builders | Представление и обработчики, изменения через команды |
| EditorManager | Буфер редактируемого блока и время жизни окна |
| SessionCheckpoints | Отсчёт активного редактирования и автоматические версии |

События разделены:

- `noteOpened` означает замену активного документа: закрывается редактор,
  отменяется его ИИ-запуск, сбрасывается время сессии.
- `noteSaved` означает подтверждённую запись. Идентичность документа и блоков
  сохраняется для очереди и обработчиков; интерфейс не открывает документ заново.
- `stateDirty` означает изменение документа командой.
- `editingActivity` учитывает ввод в окне редактора без применения его буфера.

Таймер checkpoint накапливает 15 минут редактирования. После минуты без ввода
накопление приостанавливается; autosave отсчёт не сбрасывает. Сохраняется
подтверждённое командами состояние документа. Текст открытого окна попадает в
документ по **OK**; отмена окна сохраняет прежнее поведение. Новые изменения во
время запроса checkpoint учитываются в следующем снимке. Навигация и dispose
предотвращают позднее создание снимка для другого открытого документа.

## Время жизни интерфейса

`Lifecycle` владеет обработчиками, таймерами и функциями освобождения ресурсов.
Закрытие редактора удаляет document listeners, уничтожает TipTap и Fabric,
очищает график и отложенные задачи. Повторный `dispose` безопасен. Асинхронная
загрузка рисунка завершается до OK; при закрытии её отменяют. Parser windows
сохраняют историю в скрытом DOM, освобождая обработчики перетаскивания и микрофон
при закрытии. Инициализация App и основных редакторных контроллеров идемпотентна.

## Сборка и политика браузера

`npm ci` → `npm run build` создаёт локальные JS/CSS, шрифты и иконки с хешами
содержимого. Шаблоны получают адреса из manifest. Для повторной сборки исходников
Node нужен; работающему серверу достаточно готового `static/dist`.
Старые хешированные файлы в локальном каталоге сохраняются для открытых вкладок;
при выпуске релиза следует собирать новый каталог отдельно (R6).

HTML, manifest и исходная статика не кешируются; хешированные assets получают
`max-age=31536000, immutable`. Две последовательные сборки одинаковых исходников
проверены на идентичность manifest. В R6 установка из чистого checkout также
дала совпадающий manifest; собранный архив прошёл запуск и проверку assets.

CSP для скриптов не содержит `unsafe-inline`/`unsafe-eval`. Алгоритм и переводы
передаются как inert JSON. В стилях `unsafe-inline` сохраняется из-за динамических
стилей интерфейса. Аналитика остаётся условной, по ранее выбранному cookie consent;
редактор не требует CDN.

TipTap обновлён до 3.31.3, Fabric — до 7.4.0. Для графиков используется mathjs и
SVG: `x`, `pi`, `e`, арифметика и функции sin/cos/tan/asin/acos/atan/sqrt/abs/log/exp.
Выражение ограничено 500 символами и 100 узлами AST; присваивания, доступ к полям,
матрицы и произвольные функции запрещены. Численный график строится по 541 точке;
разрывы и значения вне диапазона пропускаются. Это визуализация, не символьный анализ.

Основания: [esbuild](https://esbuild.github.io/api/),
[TipTap v3](https://tiptap.dev/docs/guides/upgrade-tiptap-v2),
[Fabric Promise API](https://www.fabricjs.com/docs/upgrading/upgrading-to-fabric-60/),
[безопасность mathjs](https://mathjs.org/docs/expressions/security.html).

## Проверки и оставшиеся границы

`npm run lint` проверяет исходный JS, `npm run check:types` — типы и валидаторы
DTO в `ApiContracts.js`. Остальные модули пока не переведены на TypeScript.
Браузерный smoke запускает отдельную БД, запрещает внешние запросы и подставляет
SSE для генерации; платные провайдеры и качество ответов моделей не проверяются.
Формулы, рисунки, графики, версии, sharing, клавиатура, узкий экран и стабильное
число document listeners проходят проверку в Chromium.

В R6 закрыт дефект общих стикеров: массив `currentNote.stickers` входит в API,
сохранение, версии, JSON примеров и текстовый экспорт. SQLite migration 002
переносит старый `sticker_text` в массив, сохраняя исходное поле. Стикеры блоков
остаются в JSON блока; публичный DTO исключает личные заметки обоих видов.
Рендер стикеров экранирует текст, дата и ID также не интерпретируются как HTML.
Панель стикеров ограничена экраном; панель действий переносится по ширине.
Сборка и проверки подключены к CI: [deployment.md](deployment.md).
